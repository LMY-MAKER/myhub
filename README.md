# myhub
模型对比笔记
1. ChatGPT（OpenAI GPT-4o/o1）
定位：全能型标杆，均衡无短板。
优势：
综合能力最强，多模态融合成熟（文 / 图 / 音 / 视频）。
生态完善，插件 / 工具链丰富，API 稳定。
逻辑推理、编程、创意写作均顶尖。
劣势：
中文理解略弱于国产模型。
价格偏高，幻觉率中等。
适合：通用场景、复杂任务、多模态创作、插件生态依赖。
2. Claude（Anthropic Claude 4/3.5 Sonnet）
定位：长文本 + 安全 + 编程强手。
优势：
上下文极强（200k–1M token），长文档分析天花板。
代码能力顶尖（SWE-bench 领先），复杂工程友好。
低幻觉、逻辑性强、安全合规性好。
劣势：
多模态偏弱（图像理解一般，无视频）。
国内访问不便，价格高。
适合：长文档 / 法律 / 学术分析、代码开发、企业知识管理、合规场景。
3. Claude Code
定位：编程专用旗舰，代码工程师级助手。
优势：
代码生成 / 重构 / 调试顶尖，复杂项目处理强。
超长记忆、逻辑清晰、vibe coding 体验好。
低幻觉、不废话、设计质感佳。
劣势：
非代码场景一般，token 消耗高。
适合：全栈开发、代码重构、技术方案设计、复杂编程任务。
4. 豆包（字节 Seed 2.0 Pro）
定位：中文原生全能助手，国内 C 端用户最多。
优势：
中文理解 / 生成顶尖，本土化优化好。
免费额度足、响应快、多模态（图 / 文 / 视频）体验好。
情绪价值高，适合日常办公 / 文案 / 轻量对话。
劣势：
专业深度（科研 / 硬核编程）不及国际旗舰。
实时信息准确性一般。
适合：中文日常办公、文案创作、生活助手、批量中文处理。
5. DeepSeek（DeepSeek-V3/R1）
定位：数学 / 代码推理专家，性价比之王。
优势：
数学推理极强（GSM8K 超 GPT-4），学术 / 数据分析友好。
代码能力接近国际一流，中文代码生成精准。
价格极低（API 便宜），轻量化部署友好。
劣势：
创意写作偏理性，多模态较弱。
服务器稳定性一般。
适合：学术研究、数据分析、编程开发、技术文档、预算敏感场景。
6. Gemini（Google Gemini 2.0/3.1 Ultra）
定位：多模态原生 + 谷歌生态，长视频理解天花板。
优势：
多模态最强（文 / 图 / 音 / 视频），支持 1 小时长视频理解。
超长上下文（百万级 token），谷歌生态深度整合。
科学推理、多语言翻译顶尖。
劣势：
中文场景优化不及国产模型。
表达偏生硬，创意性一般。
适合：跨平台办公、科研计算、多模态内容创作、谷歌生态用户。
